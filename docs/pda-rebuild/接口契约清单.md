# 接口契约清单（与旧 APK / JeecgBoot 3.5.5 兼容）

> 依据：`legacy/辰阳电子WMS_PDA_Android重建开发说明书.md` §4–§8、§15  
> **不改现网接口契约**；路径拼写错误必须原样兼容（如 `stcoktaking`、`outsoucetuiliao`）。

完整 URL = `{baseUrl}` + 下表路径。  
默认现场：`http://172.16.5.7:8080`；备选：`http://10.10.10.120:8080`。  
ngrok / 代理模式下 `{baseUrl}` = 代理完整地址（登录页配置，代理优先）。

---

## 1. 全局约定

| 项 | 值 |
|----|-----|
| API 前缀 | `/jeecg-boot/...` |
| Content-Type | `application/json` |
| 鉴权头 | `X-Access-Token: {token}`（多数 PDA 接口 Shiro `anon`，仍建议携带） |
| 成功判断 | `success == true`；失败读 `message` |
| 业务码 | 常见 `code: 200` |
| 列表数据 | `result.records` 或直接 `result`（按接口） |
| 本地持久化 | `baseUrl` / `proxyUrl` / `username` / `token` |
| ngrok | 代理非空时附加 `ngrok-skip-browser-warning: true` |
| cleartext | 内网 HTTP 需 `networkSecurityConfig` 允许 |

### 1.1 登录

- **POST** `/jeecg-boot/sys/mLogin`

请求：

```json
{ "username": "admin", "password": "e" }
```

响应：

```json
{
  "success": true,
  "message": "",
  "code": 200,
  "result": {
    "token": "...",
    "userInfo": { "username": "admin", "realname": "..." }
  }
}
```

### 1.2 通用 Result 信封

```json
{
  "success": true,
  "message": "",
  "code": 200,
  "result": {}
}
```

## 2. 关键请求体

### 2.1 领料扫码提交（生产 / 委外）

```json
{
  "fk_outsourcedetail": "子单/详情ID",
  "deliveryno": "主单ID",
  "scanner": "操作人用户名",
  "needqty": "需发数量",
  "barcodelist": ["条码1", "条码2"],
  "scanqtyList": ["实发数量1", "实发数量2"],
  "restqtyList": ["余量1", "余量2"]
}
```

- `POST /jeecg-boot/produce_material_barcode/produceMaterialBarcode/addpda`
- `POST /jeecg-boot/outsource_barcode/outsourceBarcode/addpda`

### 2.2 库存初始/快捷入库 `WarehouseBarcode`

```json
{
  "sku": "储位码",
  "creator": "操作人",
  "barcodelist": ["物料*数量*..."],
  "restqtylist": ["数量1", "数量2"]
}
```

- `POST /jeecg-boot/warehouselog/warehouselog/addpda`

### 2.3 盘点 / 移库

- `stcoktaking`、`stockmoving`：Body 为 `List<Warehouselog>`（字段以后端实体为准）
- 文案痕迹字段：`jystaff`、`jyremark`、`ykstaff` 等

### 2.4 列表查询常见参数

`userName` / `username`、`searchValue`、`id`、`barcode`、`matcode`、`deliveryno`、`orderNo`

## 9. Shiro 说明

后端 `ShiroConfig.java` 中 `//CYWMS` 段将大量 PDA 路径设为 `anon`。  
开发时：**不要擅自改严/改松现网鉴权**；客户端仍携带 Token。

## 10. 联调最小闭环（优先）

1. `POST mLogin` → 存 token  
2. 生产领料 `list2` → 明细 → `verify` → `addpda` → `changestatus`  
3. 同一链路验证委外领料  
4. `stcoktaking` / `stockmoving` 各跑一单  

写库前优先测试单 / 测试库。联调账号（谨慎）：`admin` / `e`。
