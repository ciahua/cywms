## 3. 新首页信息架构（UI 重设计，功能不丢）

旧版 14 宫格扁平排列；新版按作业类型分组，组内仍覆盖上表全部入口：

```
登录（服务器 IP:端口 + ngrok 代理）
 └─ 主界面 Home Hub
     ├─ 领料作业   生产领料 / 委外领料 / 物料超领
     ├─ 入库作业   快捷入库 / 呆料入库 /（物料入库单）
     ├─ 成品作业   成品入库 / 成品出库
     ├─ 退料作业   生产退料 / 退料出库 /（委外退料）
     ├─ 盘点作业   仓库盘点 / 成品盘点
     ├─ 库内作业   移库 / 换标 / 重检
     └─ 我的       环境信息 / 检查版本 / 退出
```

现场若强依赖旧宫格顺序，可在「我的」提供「经典宫格布局」开关；默认使用分组布局。

## 4. 典型作业流（所有领料/入库类通用）

```
选单据 list1/2/3
  → 明细 query*Detail*
  → 扫码 verify / getrestqty / checkinfifo
  → 本地累计条码
  → 提交 addpda / addlist / addBarcodeList / add1..add5
  → 改状态 changestatus / completeorder / finishorder / changemainstatus
```

## 5. 扫码约定（必须兼容）

| 项 | 值 |
|----|-----|
| Intent Action | `com.service.scanner.data` |
| Extra Key | `ScanCode` |
| 条码分段 | 常含 `*`，如 `物料代码*数量*...` |
| 其它 | 长度校验（+5 冗余）、防重复扫、震动反馈 |
