# 江苏辰阳电子 WMS · PDA Android 重建开发方案

> **权威依据**：`legacy/辰阳电子WMS_PDA_Android重建开发说明书.md`（2026-08-09）  
> **配套**：`模块功能矩阵.md`、`接口契约清单.md`  
> **原则**：对接现有 JeecgBoot 3.5.5，**不改现网接口契约**；原生 Android 重写（**不用 Flutter**）；UI 全面专业化重设计。

---

## 1. 结论摘要

| 维度 | 决策 |
|------|------|
| 旧包 | Flutter debug APK，包名 `com.example.cywms`，源码丢失 |
| 新栈 | **Kotlin + AndroidX**；UI 优先 **Jetpack Compose + Material 3**（亦可用 XML/ViewBinding，与说明书一致可选） |
| 后端 | JeecgBoot `3.5.5`，前缀 `/jeecg-boot/`，业务在 `jeecg-module-demo` |
| 默认 Base | `http://172.16.5.7:8080`（备选 `http://10.10.10.120:8080`） |
| 兼容 | 路径 / Method / Body 字段 / 错误拼写 URL **原样**；扫码广播参数原样 |
| UI | **不照搬旧宫格观感**：登录毛玻璃 + 仓库实景；首页按作业分类，覆盖原 14 模块 |
| 网络配置 | 登录页：**服务器 IP:端口** + **代理 URL（ngrok）**，代理优先 |

## 2. 系统拓扑

```
[PDA 原生 App]  --HTTP-->  [JeecgBoot :8080]  --MySQL-->  cywms
     |                         ^
     |（可经 ngrok 代理）        |
[管理 Web Vue3 :3100] ---------+
```

| 端 | 说明 |
|----|------|
| PDA | 扫码执行：领退料、入库、盘点、移库、换标、重检等 |
| Web | 建单、导入导出、台账、发货拣货核对、K3 同步；**无独立盘点菜单**（盘点在 PDA） |
| DB | 库名 `cywms`；只读对照字段，写操作先测环境 |

## 3. 技术选型（相对说明书的细化）

| 项 | 本方案 | 说明书建议 | 说明 |
|----|--------|------------|------|
| 语言 | Kotlin | Kotlin | 一致 |
| UI | Compose（推荐） | ViewBinding/XML | Compose 更易做毛玻璃与分组首页；扫码页同样可用 |
| 网络 | OkHttp + Retrofit | OkHttp/Retrofit | 一致；加动态 BaseUrl / 代理拦截器 |
| 存储 | DataStore 或 SharedPreferences | SharedPreferences | 存 `apiUrl`、`proxyUrl`、`username`、`token` |
| 扫码 | `BroadcastReceiver` | 同左 | Action=`com.service.scanner.data`，Extra=`ScanCode` |
| 最低 SDK | API 24–26（覆盖 Android 7–10 PDA） | 按现场 PDA | 目标 compileSdk 34 |
| 包名 | `com.chenyang.cywms` | 可选 | 无旧签名则不覆盖安装 |

工程目录：

```
android-pda/   （或 cywms-android/）
  app/src/main/java/com/chenyang/cywms/
    api/            # Retrofit = 契约清单
    model/          # DTO（字段名与后端一致，含 *_list 大小写）
    scanner/        # ScannerHelper
    ui/login|home|produce|outsource|stockin|stocktake|...
    data/prefs/     # 服务器 / 代理 / token
    util/
```

## 4. 兼容边界

### 必须兼容

- 说明书 §5 的 **14 个主模块** + 登录/版本检查；次级页按优先级补齐  
- §6 / §15 全部路径字符串（含 `stcoktaking`、`outsoucetuiliao`）  
- 登录 `POST /jeecg-boot/sys/mLogin`；成功判 `success == true`  
- Header：`Content-Type: application/json`，可选 `X-Access-Token`  
- 扫码广播与条码 `*` 分段、防重复、FIFO/余量校验语义  
- 领料 `addpda` Body 字段名（`barcodelist`、`scanqtyList`、`restqtyList` 等）

### 允许重做

- 视觉、字体、动效、首页分组（默认分组；可选「经典 14 宫格」）  
- 登录页增加代理/ngrok、连接测试、毛玻璃与实景背景  
- 提示文案润色（不改错误码依赖）

### 禁止

- 改现网 Shiro / Controller / 生产库结构（除非单独发版回归）  
- 用 Flutter 重建  
- 「纠正」后端拼写错误 URL

## 5. UI 重设计规范

### 5.1 登录页（硬性要求）

| 元素 | 规范 |
|------|------|
| 背景 | 充电器生产企业仓库 **真实高清全屏图**（edge-to-edge） |
| 遮罩 | 深色渐变，保证品牌与表单可读 |
| 品牌 | 「江苏辰阳电子 WMS」英雄级展示 |
| 登录框 | **半透明毛玻璃**（blur + 半透明填充 + 细描边） |
| 字段 | 账号、密码、记住账号 |
| 高级设置 | **服务器主机 + 端口 + 是否 HTTPS**；**代理地址（ngrok 完整 URL）**；「测试连接」 |
| BaseUrl 规则 | `proxyUrl` 非空则用之，否则 `http(s)://{host}:{port}`；业务 path 仍拼 `/jeecg-boot/...` |
| 动效 | 遮罩/表单入场；登录 loading（2～3 处有意动效即可） |

视觉方向：工业仓储 · 深蓝灰主色 + 琥珀强调；避免紫白渐变、奶油衬线风。

### 5.2 主界面

- 顶栏：品牌短名 + 当前用户实名  
- 中部：**分组入口**（领料 / 入库 / 成品 / 退料 / 盘点 / 库内），组内覆盖原 14 模块  
- 大触控热区，适合 PDA；少堆卡片仪表盘  
- 次要：检查版本、退出  

详见 `模块功能矩阵.md` §3。

### 5.3 作业页模式

列表 → 明细 → 扫码累计 → 提交 → 状态变更；扫码框常驻、枪扫自动填充；成功短振。

## 6. 网络与代理

```text
resolveBaseUrl():
  if proxyUrl.isNotBlank() → proxyUrl.trimEnd('/')
  else → "{scheme}://{host}:{port}"

每个请求 path 以 /jeecg-boot 开头（与现网一致）
ngrok 时加 Header: ngrok-skip-browser-warning: true
```

- 内网 HTTP：`networkSecurityConfig` 允许 cleartext  
- 超时：连接 15s / 读 30s  
- Debug 可打日志；Release 脱敏

## 7. 扫码（旧 APK 已确认）

```kotlin
action = "com.service.scanner.data"
extra  = "ScanCode"
```

Android 12+ 注册广播注意 `RECEIVER_EXPORTED`；连续扫禁软键盘抢焦点。
